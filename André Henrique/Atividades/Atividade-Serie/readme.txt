# 3ª Avaliação Oficial: Página de Série

Este projeto é uma página web dedicada à série **Suits**, desenvolvida para cumprir a proposta de criar uma página sobre uma série favorita utilizando HTML semântico e Bootstrap[cite: 3]. 

## Requisitos Implementados

Conforme a descrição da atividade, a página inclui os elementos estudados de forma autónoma[cite: 3]:

* **Estrutura com HTML semântico:** O ficheiro `index.html` está estruturado com as tags `<header>`, `<main>`, `<section>` e `<footer>`[cite: 3].
* **Bootstrap via CDN:** Todo o layout foi estilizado e organizado utilizando exclusivamente as classes do framework Bootstrap[cite: 3].
* **Card:** O elenco principal da série é exibido através do componente de cards do Bootstrap[cite: 3].
* **Breadcrumb:** Foi adicionada uma navegação de contexto no topo da página, indicando a localização do utilizador[cite: 3].
* **Carousel:** Criou-se um carrossel interativo com imagens de destaque relacionadas com o tema da série[cite: 3].
* **Conteúdo Relevante:** A página apresenta o título da série, a sinopse completa, o elenco principal e imagens ilustrativas[cite: 3].

## Como visualizar o projeto

1. Certifica-te de que os ficheiros do projeto não contêm pastas desnecessárias.
2. Abre o ficheiro `index.html` num navegador web.
3. É necessária uma ligação ativa à internet para que o Bootstrap seja carregado corretamente através da CDN.

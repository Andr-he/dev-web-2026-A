# 🦍 Planeta dos Macacos - Página Web

Projeto desenvolvido como atividade prática de desenvolvimento web, com o objetivo de criar uma página dedicada ao clássico filme **Planeta dos Macacos** (1968), aplicando conceitos fundamentais de HTML5 e CSS3.

## 📋 Sobre o Projeto

A página apresenta informações essenciais sobre o filme, incluindo título, sinopse, visão geral, diretor, elenco e imagem de capa, estruturados de forma semântica e estilizados externamente.

## 🚀 Conceitos Aplicados

* **HTML Semântico:** Estruturação da página utilizando tags como `<header>`, `<main>`, `<section>`, `<article>` e `<footer>` para melhor organização e acessibilidade[cite: 2].
* **CSS Externo:** Estilização separada da estrutura HTML através do arquivo `estilo.css` (ou `style.css`)[cite: 2].
* **Variáveis CSS:** Definição de paleta de cores, tipografia e espaçamentos utilizando variáveis no seletor `:root`[cite: 2].
* **Layout Moderno:** Uso de **Flexbox** / **CSS Grid** para alinhamento e organização dos elementos na tela[cite: 2].
